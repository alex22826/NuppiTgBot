НАСТРОЙКА СОЗДАТЕЛЯ И СОТРУДНИКОВ

Бот закрытый: регистрации и административных команд в нём нет.

1. Создатель
   - Отправьте боту /my_id и скопируйте число.
   - В .env рядом с bot.py укажите: CREATOR_TELEGRAM_ID=ВАШ_ID
   - Перезапустите бота. Создатель всегда пропускается проверкой доступа,
     но чтобы отправлять фото, его тоже нужно добавить сотрудником (шаг 2).

2. Сотрудники (медики и операторы)
   Сотрудник сначала отправляет боту /my_id и сообщает вам свой ID.
   Добавить его можно на сайте (кнопка «Добавить сотрудника») или из терминала:

   python manage_users.py add TELEGRAM_ID "ФИО" Город "Роддом 1, Роддом 2"
   python manage_users.py add TELEGRAM_ID "ФИО" Город "Роддом" --role Оператор
   python manage_users.py list
   python manage_users.py disable TELEGRAM_ID
   python manage_users.py enable TELEGRAM_ID

   Медик отправляет фото (/send_photo) и смотрит свои отчёты.
   Оператор получает отчёт за 10 дней и считает фото по Excel-файлу.

3. Часы работы
   По умолчанию бот принимает сообщения с 07:00 до 19:00 по Ташкенту.
   Изменить можно в .env: BOT_WORK_START_HOUR и BOT_WORK_END_HOUR
   (0 и 24 — круглосуточно).
