# Сайт-панель для Nuppi Telegram Bot

Сайт показывает фотографии, которые уже сохранены Telegram-ботом в `medical_bot.db`. База бота открывается только для чтения: сайт не изменяет фотографии, медиков или отчёты.

## Установка в PyCharm

1. Создайте новую папку проекта, например `NuppiWeb`, и распакуйте в неё архив сайта.
2. В терминале PyCharm выполните:

```powershell
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

3. Откройте `.env` и проверьте `BOT_DB_PATH`. Там должен быть полный путь к файлу `medical_bot.db` вашего Telegram-бота. В `CREATOR_DJANGO_USERNAME` укажите логин, который вы создадите на следующем шаге (например, `admin`).
4. Создайте таблицы сайта и свою учётную запись создателя:

```powershell
python manage.py migrate
python manage.py createsuperuser
```

5. Запустите сайт:

```powershell
python manage.py runserver
```

6. Откройте `http://127.0.0.1:8000/login/` и войдите с данными, созданными на шаге 4.

## Права и управление пользователями

Только вход с логином из `CREATOR_DJANGO_USERNAME` может добавлять, изменять и отключать сотрудников. Доступ к Telegram-боту будет отключён, а фотографии останутся в базе и продолжат отображаться на сайте.

На главной странице создатель может создать обычный вход оператору. Такой оператор не получает доступа к `/admin/`, данным сотрудников и кнопкам изменения; он видит фотографии, скачивает их и выгружает Excel для редактирования на своём компьютере.

Для работы этой кнопки замените также `bot.py` одноимённым файлом из корня архива и перезапустите Telegram-бота.

## Возможности

- вход по паролю;
- отдельные права создателя и операторов;
- количество фотографий и отправителей;
- фильтры по городу и роддому;
- скачивание выбранной выгрузки Excel и отдельных фото;
- просмотр фотографий, имени врача, даты на упаковке, номера на упаковке и ФИО роженицы;
- данные берутся напрямую из базы бота.

Для работы в интернете вместо локального компьютера потребуется сервер и отдельная настройка безопасности (`DJANGO_DEBUG=0`, безопасный `DJANGO_SECRET_KEY`, домен, HTTPS).
