# Сайт-панель NuppiTgBot

Сайт показывает фотографии, которые сохранил Telegram-бот в `medical_bot.db`, и даёт
оператору принимать или отклонять их, править данные и выгружать отчёты Excel.

Установка, настройки и запуск описаны в [README в корне проекта](../README.md).
Коротко:

```bash
cd django_portal
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Сайт читает общий `.env` из корня проекта (значения из `django_portal/.env`, если он есть,
имеют приоритет) и по умолчанию открывает ту же базу `medical_bot.db`, что и бот.

## Права

- **Создатель** — логин из `CREATOR_DJANGO_USERNAME`, а если он не задан — любой суперпользователь.
  Управляет сотрудниками, роддомами, заданиями и создаёт входы операторов.
- **Оператор** — обычный вход без доступа к `/admin/` и данным сотрудников: смотрит фото,
  ставит решения, правит дату, ФИО и QR, выгружает Excel.

Пароли проверяются стандартными правилами Django: не короче 8 символов, не только цифры,
не из списка распространённых.
