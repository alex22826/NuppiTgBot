Эталонные упаковки для проверки дизайна
========================================

В папке reference_packaging находятся две эталонные упаковки, предоставленные заказчиком:
- nuppi_gold_1_300.png
- nuppi_f_1_300.png

При обработке фото бот передаёт их ИИ вместе с новой фотографией. Фото принимается только если:
- название NUPPI / NUPPI Gold и номер 1 ясно видны;
- дизайн совпадает с одним из эталонов;
- пингвин, цвета и расположение ключевых элементов не имеют заметных изменений;
- дата и ФИО роженицы распознаны.

Не удаляйте и не переименовывайте папку reference_packaging.
