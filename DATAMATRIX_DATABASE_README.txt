База разрешённых Data Matrix-кодов
==================================

Разрешённые региональные префиксы и диапазоны номеров хранятся в
QR_REGION_RANGES внутри bot.py. Диапазоны объединяют данные предыдущей
таблицы и файла «наклейки счёт (2).xlsx».

Бот использует zxing-cpp для Data Matrix и QR-кодов. Установите зависимости:

python -m pip install -r requirements.txt

Статусы на сайте:
- Код внутри разрешённого диапазона — регион распознан.
- Распознанный код неизвестного формата, префикса или вне диапазона —
  посторонний QR/Data Matrix; фотография автоматически попадает в «Отклонено».
- Код отсутствует — допустимо и само по себе не является причиной отклонения.

Эта проверка устанавливает только совпадение кода. Оценка Sightengine
отдельно показывает вероятность ИИ-генерации изображения.
